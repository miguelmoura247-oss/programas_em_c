# Funcionalidade
Um código simples em c que cria uma estrutura chamada aluno, que armazena o nome e duas notas de
cada estudante. No programa principal, o usuário informa a quantidade de alunos. 
Depois, a função print_aprovados recebe os dados, solicita o nome e as duas notas de 
cada aluno, verifica se as notas são válidas, calcula a média e informa se o aluno foi 
aprovado (média ≥ 6) ou reprovado (média < 6).
