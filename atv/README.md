Exercício: Arquivos em C

Projeto simples para gravar e ler dados em arquivo binário usando:

Struct.

Arquivos

modulo.h: Estrutura pessoa (nome, idade, CPF).

exArq.c: Grava dados de 5 pessoas no arquivo arquivo.txt.

lerarquivo.c: Lê e exibe os dados do arquivo no terminal.

makefile: Automatiza a compilação.

Como Executar

# 1. Compilar o projeto
make

# 2. Cadastrar as pessoas (gravar no arquivo)
./gravar

# 3. Mostrar os dados na tela (ler do arquivo)
./ler

# (Opcional) Limpar executáveis e arquivos gerados
make clean
